### 定时器参数及 PWM 语义

| 定时器 | 时钟来源                                 | PSC                          | ARR                              | 默认输出 / 更新频率                       |
| ------ | ---------------------------------------- | ---------------------------- | -------------------------------- | ----------------------------------------- |
| TIM1   | PCLK，当前 72 MHz                        | 71                           | 999                              | PWM 1 kHz；更新中断 1 kHz；每个计数 1 μs |
| TIM3   | PCLK；APB 分频时定时器时钟为 PCLK 的两倍 | 动态计算，72 MHz 时为 1      | 动态计算，72 MHz 时为 35999      | ADC 触发 1 kHz                            |
| TIM16  | PCLK；APB 分频时定时器时钟为 PCLK 的两倍 | 动态计算，默认 72 MHz 时为 1 | 动态计算，默认 72 MHz 时为 35999 | PB6 PWM 默认 1 kHz                        |

频率计算：`F = F_TIM / ((PSC + 1) × (ARR + 1))`。修改 TIM3 频率使用 `TIM3_ADC_SAMPLE_FREQUENCY_HZ`；修改 TIM16 频率使用 `bsp_tim16_ch1_pwm_setfrequency()`，实际频率受整数分频限制。

| 占空比参数 | M_PWM 高电平占空比（TIM1 经 Q11 反相后） | PB6 高电平占空比（TIM16） |
| ---------- | ---------------------------------------- | ------------------------- |
| 0          | 0%，恒低                                 | 0%，恒低                  |
| 500        | 50%                                      | 50%                       |
| 1000       | 100%，恒高                               | 100%，恒高                |

两路均使用比较寄存器预装载。TIM1 接口为 `bsp_tim1_ch1_pwm_setduty()`；TIM16 接口为 `bsp_tim16_ch1_pwm_setduty()`。TIM1 初始化后自动启动；TIM16 初始化后也自动启动；TIM3 需要单独调用 Start，避免 ADC 尚未就绪时提前触发。

### ADC 扫描序列及 DMA 缓冲区

| Rank | 缓冲下标 / 枚举    | 信号            | 硬件通道               | 引脚     |
| ---- | ------------------ | --------------- | ---------------------- | -------- |
| 1    | 0 / ADC_CH_MOTOR   | 电机电流反馈    | ADC_IN5                | PA5      |
| 2    | 1 / ADC_CH_WH      | WH 模拟反馈     | ADC_IN6                | PA6      |
| 3    | 2 / ADC_CH_SW      | 模拟按键 / 开关 | ADC_IN7                | PA7      |
| 4    | 3 / ADC_CH_USB     | USB/VIN 电压    | ADC_IN8                | PB0      |
| 5    | 4 / ADC_CH_NTC     | NTC 温度        | ADC_IN9                | PB1      |
| 6    | 5 / ADC_CH_PGA2    | PGA2 输出       | LL_ADC_CHANNEL_OPA2    | 内部通路 |
| 7    | 6 / ADC_CH_VREFINT | 内部参考源      | LL_ADC_CHANNEL_VREFINT | 内部通路 |

- ADC 时钟当前为 PCLK/4，即 18 MHz；各通道采样时间为 640.5 个 ADC 时钟周期。
- 规则组单次扫描，TIM3 每次 TRGO 触发整组 7 个通道，不是每次只触发一个通道。
- 当前 `ADC_USE_DMA = 1`，DMA1 Channel1 映射为 ADC 请求，外设和内存均按 32 bit 搬运，内存地址递增。
- `ADCxConvertedDatas[7]` 占用 28 字节 RAM；DMA 每组传输 7 个数据，块传输完成后通知应用层。
- OPA2 的内部 ADC 输出不占用 PB4 外部输出脚，但 PGA2 仍使用 PB3、PA15 作为模拟输入。

推荐接入顺序：先初始化 GPIO、PGA2 和 TIM3，再初始化并启动 ADC/DMA，最后调用 `bsp_tim3_Start()`。停止采样时先停止 TIM3，再停止 ADC，防止在 ADC 停止期间继续产生触发。

### EXTI 与中断分配

| 资源 / 中断              | 用途                 | 模式 / 优先级     | 说明                                                           |
| ------------------------ | -------------------- | ----------------- | -------------------------------------------------------------- |
| EXTI8 / PA8              | FAN_SW 唤醒          | 上升沿 Event      | 不开启按键 CPU 中断                                            |
| EXTI9 / PA9              | MIST_SW 唤醒         | 上升沿 Event      | 不开启按键 CPU 中断                                            |
| EXTI10 / PA10            | USB_IN               | 上升沿 IT + Event | CPU 中断与唤醒事件同时配置                                     |
| EXTI4_15_IRQn            | USB 插入中断         | 2                 | 当前 ISR 清除 Line10 标志，业务通知尚未实现                    |
| TIM1_CC_IRQn             | CH4 输入捕获         | 0                 | 回调`bsp_tim1_ch4_inputCapture_Callback()`，风机模块提供实现 |
| TIM1_BRK_UP_TRG_COM_IRQn | TIM1 溢出累计        | 1                 | 当前只处理更新事件                                             |
| DMA1_Channel1_IRQn       | ADC 整组数据完成     | 0                 | DMA 模式下启用                                                 |

## BMS控制说明

### VIN_EN/VBAT_EN控制

```Lua
VIN_EN = 1  → 允许 USB 输入
VIN_EN = 0  → 切断 USB 输入

VBAT_EN = 1 → 接通 VBAT 到 IP5326 BAT 的通路
VBAT_EN = 0 → 关闭该通路；不表示切断 MCU 所用的 VBAT 网络
VIN_EN  = 高
    → 保留 USB 输入通路
    → 休眠时仍可插 USB / 充电 / 触发 USB 检测

VBAT_EN = 低
    → 关闭电池输出通路
    → 减少电池继续给后级供电
    → 降低待机功耗
```

### IP5326 - KEY控制

| KEY 按下时间/动作          | IP5326 功能                                      |
| -------------------------- | ------------------------------------------------ |
| `< 70 ms`                | 不响应                                           |
| `> 100 ms 且 < 2 s`      | **短按**：开启电量显示灯，同时开启升压输出 |
| `> 2 s`                  | **长按**：进入待机状态                     |
| `1 s 内连续两次短按`     | 打开/关闭照明灯                                  |
| 长按进入待机时照明灯已开启 | 照明灯仍保持开启，需要双击关闭                   |

### IP5326 2灯模式 LED 逻辑

LED2 经 1kΩ 电阻连接 BAT，LED1/LED3 分别驱动 D1/D2。主控板采集 LED1/LED3，可按两灯模式识别以下状态：

| 状态     | D1（LED1） | D2（LED3） |
| -------- | ---------- | ---------- |
| 充电过程 | 0.5Hz 闪烁 | 灭         |
| 充满     | 亮         | 灭         |
| 正常放电 | 灭         | 亮         |
| 低电量   | 灭         | 1.0Hz 闪烁 |

`bms_status` 在观察到足够的闪烁周期或常亮时间后才更新 `mode`；全灭、双灯异常及观察期返回 `BMS_STATUS_UNKNOWN`。低电量显示不代替电池电压采样或软件欠压保护。

### IP5326 1灯模式 LED 逻辑

只读取 LED1：0.5Hz 闪烁为充电中，1Hz 闪烁为低电量；常亮在充满和正常放电中相同，需要结合去抖后的 USB 输入区分。`BMS_STATUS_LED_MODE` 设为 `BMS_STATUS_MODE_1_LED` 时启用。

### IP5326 4灯模式 LED 逻辑（仅供参考）

以下为四灯模式参考表。当前硬件使用两灯模式，不能把两路 GPIO 电平解释为四个电量档位或准确百分比。完成 LED2/LED4 的板级接线与输入配置后，可将 `BMS_STATUS_LED_MODE` 设为 `BMS_STATUS_MODE_4_LED`，由 `mode`、`solidLeds` 和 `flashingLed` 解读下表。即使识别出电量区间，也不据此直接判定软件保护故障。

#### 放电

| 电池状态            | D1        | D2 | D3 | D4 |
| ------------------- | --------- | -- | -- | -- |
| 放电 C ≥ 75%       | 亮        | 亮 | 亮 | 亮 |
| 放电 50% ≤ C < 75% | 亮        | 亮 | 亮 | 灭 |
| 放电 25% ≤ C < 50% | 亮        | 亮 | 灭 | 灭 |
| 放电 3% ≤ C < 25%  | 亮        | 灭 | 灭 | 灭 |
| 放电 0% < C < 3%    | 1 Hz 闪烁 | 灭 | 灭 | 灭 |

#### 充电

| 充电状态       | D1          | D2          | D3          | D4          |
| -------------- | ----------- | ----------- | ----------- | ----------- |
