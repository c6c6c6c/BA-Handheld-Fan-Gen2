# 芯片资源说明

## BMS控制说明

### VIN_EN/VBAT_EN控制
```
VIN_EN = 1  → 允许 USB 输入
VIN_EN = 0  → 切断 USB 输入

VBAT_EN = 1 → 允许电池接入 VBAT
VBAT_EN = 0 → 切断电池输出
VIN_EN  = 高

    → 保留 USB 输入通路
    → 休眠时仍可插 USB / 充电 / 触发 USB 检测

VBAT_EN = 低
    → 关闭电池输出通路
    → 减少电池继续给后级供电
    → 降低待机功耗
```
### IP5326 - KEY控制
| KEY 按下时间/动作 | IP5326 功能 |
|---|---|
| `< 70 ms` | 不响应 |
| `> 100 ms 且 < 2 s` | **短按**：开启电量显示灯，同时开启升压输出 |
| `> 2 s` | **长按**：进入待机状态 |
| `1 s 内连续两次短按` | 打开/关闭照明灯 |
| 长按进入待机时照明灯已开启 | 照明灯仍保持开启，需要双击关闭 |

### IP5326 4灯模式 LED 逻辑

#### 放电
| 电池状态 | D1 | D2 | D3 | D4 |
|---|---|---|---|---|
| 放电 C ≥ 75% | 亮 | 亮 | 亮 | 亮 |
| 放电 50% ≤ C < 75% | 亮 | 亮 | 亮 | 灭 |
| 放电 25% ≤ C < 50% | 亮 | 亮 | 灭 | 灭 |
| 放电 3% ≤ C < 25% | 亮 | 灭 | 灭 | 灭 |
| 放电 0% < C < 3% | 1 Hz 闪烁 | 灭 | 灭 | 灭 |

#### 充电
| 充电状态 | D1 | D2 | D3 | D4 |
|---|---|---|---|---|
| 已充满 | 亮 | 亮 | 亮 | 亮 |
| C ≥ 75% | 亮 | 亮 | 亮 | 0.5 Hz 闪烁 |
| 50% ≤ C < 75% | 亮 | 亮 | 0.5 Hz 闪烁 | 灭 |
| 25% ≤ C < 50% | 亮 | 0.5 Hz 闪烁 | 灭 | 灭 |
| C < 25% | 0.5 Hz 闪烁 | 灭 | 灭 | 灭 |
